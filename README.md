# 🛒 E-Commerce Web Application

A modern full-stack E-Commerce Web Application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).  
This platform allows users to browse products, add items to cart, place orders, and manage products through an admin dashboard.

---

## ✨ Features

### 🔐 Authentication & Authorization
- User Registration & Login
- JWT Authentication
- Role-Based Access (Admin/User)
- Protected Routes

### 🛍️ E-Commerce Functionalities
- Product Listing
- Product Details Page
- Add to Cart
- Shopping Cart Management
- Checkout System
- Order Tracking
- Product Search & Filters

### 👨‍💼 Admin Dashboard
- Add Products
- Update Products
- Delete Products
- Manage Orders
- Manage Users

### 🎨 UI/UX
- Fully Responsive Design
- Modern Product Cards
- Smooth Animations
- Toast Notifications
- Mobile Friendly Layout

---
